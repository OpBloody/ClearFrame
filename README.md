# ClearFrame 🔍

**ClearFrame** is a lightweight, frameless, and draggable GUI built with [DearPyGui](https://github.com/hoffstadt/DearPyGui).  
Designed for Python developers who want a sleek, minimal interface without the standard window borders or title bar. Perfect for floating tools, custom dashboards, or overlay applications.

---

## Features

- Frameless, borderless window
- Smooth, incremental drag movement
- Easy to integrate into Python projects
- Fully customizable DearPyGui interface

---

## Installation

```bash
git clone https://github.com/yourusername/ClearFrame.git
cd ClearFrame
pip install dearpygui
```

**Why This Project Exists:**  
My goal with this project is to help future developers use DearPyGui to create powerful, modern-looking GUIs **without that ugly default viewport window**. This is a small experiment in building sleek, frameless, and draggable interfaces that feel professional and lightweight.
